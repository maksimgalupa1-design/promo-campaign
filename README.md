# Promo Campaign: серверная часть

Настоящий вход через TikTok и анализ роликов. Без внешних пакетов, нужен Node 18+.

## Как это работает

1. Автор вставляет ссылку на свой аккаунт. Кнопка «Открыть в TikTok» ведёт на `/auth/tiktok?u=логин`. Сервер отправляет человека в TikTok на страницу разрешения.
2. Человек нажимает «Разрешить», TikTok возвращает его на `/auth/tiktok/callback` с кодом.
3. Сервер меняет код на токен, проверяет, что подтверждённый в TikTok аккаунт совпадает со ссылкой, и загружает профиль и список роликов за последние 200 дней.
4. `analysis.js` считает ролики и просмотры за сегодня, 7 дней и 30 дней.
5. Пустой аккаунт и аккаунт без роликов дольше 120 дней не принимаются. Если роликов за 30 дней нет, но последний был недавно, шанс 17%.
6. Автор вводит свою цену (`POST /api/price`), сайт отвечает шансом, списком «хорошо» и «плохо» и решением.
7. Владелец видит всех авторов с решением «брать или нет» на `GET /api/admin/applicants`.

## Запуск

```
export TIKTOK_CLIENT_KEY=...        # из TikTok for Developers
export TIKTOK_CLIENT_SECRET=...
export PUBLIC_URL=https://ваш-домен # обязательно https
export ADMIN_TOKEN=длинный-случайный-пароль
node server.js
```

Сайт уже лежит в `public/index.html`. Это та же страница, что и прототип: если её открыть через этот сервер, она сама переключается с тестовых аккаунтов на настоящие данные TikTok (кнопка «Открыть в TikTok» ведёт на `/auth/tiktok`, анализ берётся из `/api/me`, цена уходит в `/api/price`).

Сайт должен открываться по https, иначе браузер не сохранит cookie входа. Для проверки на своём компьютере используйте https-туннель.

Пока на сервере хранятся только вход, ролики, анализ и цена. Заявки, ссылки и выплаты остаются в браузере, их тоже нужно перенести в базу.

## Настройка в TikTok for Developers

1. Создайте приложение на developers.tiktok.com и добавьте продукт Login Kit.
2. В Redirect URI впишите `https://ваш-домен/auth/tiktok/callback` (точно как в `PUBLIC_URL`).
3. Запросите разрешения (scopes) `user.info.basic`, `user.info.stats`, `video.list`.
4. Пройдите проверку приложения (app review) со ссылками на политику конфиденциальности и условия. Пока она не пройдена, войти смогут только тестовые пользователи, добавленные в приложение.

Названия адресов, полей и разрешений я писал по памяти. Перед запуском сверьте их с текущей документацией TikTok for Developers: она может отличаться.

## Что важно знать

- API отдаёт общее число просмотров каждого ролика, а не просмотры по дням. Поэтому «за сегодня», «за 7 дней» и «за 30 дней» здесь означают ролики, опубликованные за этот период, и их просмотры. Чтобы считать прирост просмотров по дням, нужно раз в сутки сохранять снимок `view_count` и вычитать.
- Токены лежат в `data.json` в открытом виде. Для рабочего сайта храните их в базе с шифрованием.
- Пароль TikTok сайт не получает, только токен с разрешёнными правами. Автор может отозвать доступ в настройках TikTok.
- Реквизиты для выплат (карта, IBAN, крипто-адреса) нельзя хранить как попало: нужна база с шифрованием и платёжный провайдер. Код на обороте карты (CVV) для выплат не нужен и запрашивать его нельзя.
- Проверка цен и порогов шанса: все числа в `evaluate()` в `analysis.js`. Подберите их под свои кампании.
